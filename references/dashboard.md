# live 档案：3D 知识图谱工作台

每个孩子的档案（`learner.json`）除了文字视图，还有一张 live 的脸：
`<孩子>/知识图谱.html`——整份数学图谱的 3D 工作台，单文件，双击就能开，
离线、手机上也能看。它回答「这个孩子在整张图里走到了哪」，一眼看到全局；
精确的、能打印的版本是 `learner.py map` 出的静态知识地图，两样都是档案的视图，
判断还在档案里。

## 怎么生成

```bash
python3 scripts/learner.py dashboard <孩子>   # 写出 <孩子>/知识图谱.html
python3 scripts/dashboard.py <孩子>           # 同上，直接调生成器
```

`learner.py add` 之后会自动刷一遍（刷不上只报一声，不挡写档；手动刷用上面两条）。
每次重建，节点位置不变（位置由节点 id 的哈希决定），亮起来的地方越长越多。

## 图里有什么

- **870 个课标节点**：cn-math 数学四领域（数与代数 / 图形与几何 / 统计与概率 /
  综合与实践）。topics.json 里一共 3421 个点，其余是语文、英语、科学等学科，
  不在本 skill 的范围。
- **认知节点**（紫色）：档案里建的课标以下的命题（「0 是起点」「点数＝段数＋1」），
  挂在锚点课标节点外侧。
- **分层**：年级×学期从下往上排，先修在下、后继在上；层内按领域分扇区、按章节排角度。
- **颜色即状态**：红（有问题）、琥珀（存疑）、薄荷绿（会）、暗灰（没碰过）。
  推断出来的状态（推断会 / 上游待查 / 可能受影响）暗一档——与知识地图的虚线框同理，
  只是提示，不进档案。
- **边**：先修 → 后继，硬边亮一点；紫色虚线是认知节点到锚点的挂线。

## 能做什么

- 拖动旋转、滚轮缩放；双击空白处回到全图。
- 点一个节点：左边面板给它的状态、证据、相关猜测，并高亮它的上游链（青色）
  与下游牵连（紫色），其余暗下去。
- 搜节点名；按状态筛（已点亮 / 有问题 / 存疑 / 推断 / 没碰过）；
  点一条猜测，飞到它挂的节点；点右上角「已点亮」，飞到亮点簇。
- 远看不标字（亮点簇的字会糊成一团），凑近了、或选中了，才标；悬停随时有名字。

## 为什么这样设计

- **3D 只管全局，精读靠面板。** 3D 有遮挡和景深，读不准具体关系；证据、猜测、
  待收回的卷子都在左边面板里，两边各管一段。
- **分层不用力导向。** 870 个点力导向出来是一团毛球，什么结构都看不见；
  按年级分层，先修往上流，形状本身就是「越学越往上走」。
- **打包后的 JS 提交在仓库里。** `scripts/dashboard/dashboard.bundle.js` 是
  app.js + Three.js 打包、压缩后的单个文件（约 600 KB），生成它才需要 Node；
  平时跑 dashboard.py 只需要 Python。改了 app.js 之后重打 bundle 的办法见
  `scripts/dashboard/README.md`。

## 文件

| 文件 | 是什么 |
|---|---|
| `scripts/dashboard.py` | 生成器：提数学全图、算状态与布局、拼出单文件 HTML |
| `scripts/dashboard/app.js` | 前端源码（Three.js 场景与交互） |
| `scripts/dashboard/template.html` | 页面模板 |
| `scripts/dashboard/dashboard.bundle.js` | 打包后的前端（生成的，提交在仓库里） |
| `scripts/dashboard/package.json` | 重打 bundle 时用（three + esbuild） |
