# 题型库：补边的五种构造

出卷时按图谱节点选构造。所有构造的共同点：**题目要让错误的边当众失败**，而不是绕开它。每种构造给范例（出自 examples/fraction-1-11）与换概念时的找法。

## 1. 撤支架三件套（诊断探针，每个关键节点必备）

同一个动作出三级，支架逐级撤掉：

| 级 | 支架 | 测什么 |
|---|---|---|
| 控制题 | 支架全在，流程照着做就能对 | 他「会不会做这道题」（流程记忆） |
| 变式题 | 换一个条件，流程蒙不了 | 他靠的是流程还是概念 |
| 断尺题 | 关键支架直接不存在 | 概念本身在不在 |

范例（测量）：对齐 0 量（控制）→ 物体移位、从刻度 2 开始（变式，读末数立刻露馅）→ 尺子断掉 0 那截（断尺，无末数可读，只能数格）。

换概念找法：问自己「这个概念里，孩子最可能拿什么当拐杖？」——拐杖就是支架（末尾的数、图上的现成编号、公式的第一步）。三级就是：拐杖在 → 拐杖换位置 → 拐杖拿走。**只有控制题对、后两级错，才算确诊概念没过**；三级全错是技能问题，回骨架层。

## 2. 编号写进「肚子」里（把计数对象逼出来）

凡是「数错对象」类断边（数点当数份、数面当数体、数角点当数角），让孩子先给**被数对象本身**编号再回答：给段的肚子编号、给每个小正方形编号。编号位置就是他的计数对象，写在点上还是段上一眼可见，等于把推理链画在卷子上。编号后再问总数与单位量，错无可错。

## 3. 错题诊所（原题复现）

把原题原样搬进卷子（图重绘、参数一致），附上孩子的原始错误答案写成「小明说：……」，四问固定：

1. 他数/想的是（ A / B ）？——指认对象
2. 正确的应该是多少？——重做
3. 验算：用校验边算一遍，错答案过不了关——让他亲手推翻
4. （可选）一句话告诉小明他错在哪

用「小明」不用「你」：诊别人的错没有防御，诊出的是同一条边。

## 4. 校验边（每卷必备一条）

一条孩子能独立执行的恒等关系，写完答案自己验：

- 分数：`一份 × 份数 ＝ 1`
- 测量：`起点刻度 + 走了几格 ＝ 终点刻度`
- 乘法：`积 ÷ 一个因数 ＝ 另一个因数`（或用加法连加验乘法）
- 面积：`拼回去要严丝合缝 / 总面积 ＝ 各块之和`

选边的标准：只用已过关的节点就能算；算出的矛盾要足够刺眼（10 × 1/11 ≠ 1）。卷首规矩、自查清单里都要出现它，把它变成孩子的习惯而不是一道题。

## 5. 迁移题与毕业题（收口）

- **迁移题**：同一条边换一个生活外壳，图形、数字、问法全变，只留结构。范例：「平均剪成 10 段要剪几刀」——剪刀数 = 段数 − 1，与点段关系同构。选外壳的标准：孩子没法背题型，只能调结构。
- **毕业题**：全卷图谱的一次综合，至少串起两个节点，且含一个小陷阱（范例：两颗 ★ 相隔几份——既要读位置，又要数两人之间的段）。放在最后，过了才算图谱接通；家长页的「收官」判据就指它和原题复测。

## 判读树的写法（家长页）

每个关键节点一行，格式恒定：

> 第 X 题答成 A（写出预期的典型错答，如「读末数答 8」）→ 节点 N 没过 → 实物游戏 G（两三分钟）→ 回到第 M 题的动作重做。

要点：

- 错答要**预写出来**，家长对号入座，不靠家长理解数学；
- 实物游戏优先于再做纸题——断边多在实物层，纸面重复只是练流程；
- 给收官条件：原题答对 + 能讲出关键关系（如「点数＝段数＋1」）＝ 本案关闭，缺一不可。

## 已见误解模式清单（只存模式，不存图谱）

新案遇到新模式才往这里加一行；出卷时先扫一遍本表，命中的模式有现成的探针构造可套。

| 模式 | 长相 | 典型探针 |
|---|---|---|
| 点段不分 | 数端点/刻度当份数，分母、总数多 1 | 篱笆题（柱子 vs 栏杆）、编号写进肚子、剪刀题 |
| 0 无起点义 | 0 只当「没有」，量东西读末数、把 0 改成 1 再数 | 移位量、断尺量、从任意刻度起画定长线 |
| 定义会背、图上不会 | 背诵题全对，换表征就错 | 同一概念换三种表征连出（实物图 / 线段图 / 数轴） |
| 整体认错 | 单位「1」指错对象（把一份当整体、把多份当整体） | 整体涂色指认、同一图问两次「这里的 1 是谁」 |
| 位置/数量错接 | 两个量身份互换：把数对了的格数写进终点刻度槽（错值＝题中另一正确量，巧合检验可判），再按错位的值二次运算；常伴回代校验边缺失（起点＋格数落不回终点也无人拦） | 两量分工反序填（先数格写格数、再回头读终点）、每题强制回代一行（起点＋格数＝？对着图核终点） |
