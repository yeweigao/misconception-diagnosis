# 想法库：题型构造与已见的误解模式

前几案用过、确实管用的构造，记在这里备查。它们不是配方：一张卷子用哪几种、用不用，看这次要分开哪些猜测；能设计出更好的题，就用你自己的，用得好再回来补一条。

这些构造有一个共同点：**让接错的边在孩子面前失败，而不是绕开它。** 范例未注明的出自 `examples/fraction-1-11`。

| # | 构造 | 什么时候用得上 |
|---|---|---|
| 0 | 错答有信息的题 | 几乎总是：想让一道题同时分开几条猜测 |
| 1 | 撤支架三级 | 分不清他靠的是流程还是概念 |
| 2 | 编号写进「肚子」 | 怀疑他数错了对象 |
| 3 | 错题诊所 | 想让他亲手推翻原来那条错边 |
| 4 | 校验边 | 给他一个不靠老师的自检手段 |
| 5 | 反填极值脚手架 | 逆向题要连翻三层，一步到不了 |
| 6 | 规则对判别 | 成对规则混在一起串线 |
| 7 | 迁移题与毕业题 | 确认修好的是边，不是原题的长相 |
| 8 | 有提示 / 拿掉提示对照 | 怀疑他懂，但做题时没被叫出来 |

## 0. 错答有信息的题

**用处**：一道题，看他错成哪样，就知道他是哪种想法。教学研究里叫枢纽题（hinge question）。

**怎么造**：先列出这一步上孩子可能有的几种想法（包括对的那种），每种想法会算出什么答案；挑一道题，让这些答案**互不相同**。选择题就把它们都放进选项；填空题就在家长页写清「答成 A 说明……答成 B 说明……」。

**例**：比较 3/8 和 3/5。按分子比会说「一样大」；按分母当整数比会说「3/8 大」；对的是「3/5 大」。三种想法，三个答案，一道题就分开了。反过来，2/9 和 4/9 就分不开「懂」和「按整数比」，两种想法答案相同。

## 1. 撤支架三级

**治什么**：诊断探针。同一个动作出三级，支架逐级撤掉，看概念本身在不在。

| 级 | 支架 | 测什么 |
|---|---|---|
| 控制题 | 支架全在，流程照着做就能对 | 他「会不会做这道题」（流程记忆） |
| 变式题 | 换一个条件，流程蒙不了 | 他靠的是流程还是概念 |
| 断尺题 | 关键支架直接不存在 | 概念本身在不在 |

**怎么造**：问自己「这个概念里，孩子最可能拿什么当拐杖？」——拐杖就是支架（末尾的数、图上的现成编号、公式的第一步）。三级就是：拐杖在 → 拐杖换位置 → 拐杖拿走。

**判读**：控制题对、后两级错，多半是概念没过，靠的是流程；三级全错更像技能问题，回骨架层看。

**范例**（测量）：对齐 0 量（控制）→ 物体移位、从刻度 2 开始（变式，读末数立刻露馅）→ 尺子断掉 0 那截（断尺，无末数可读，只能数格）。

## 2. 编号写进「肚子」里

**治什么**：「数错对象」类断边——数点当数份、数面当数体、数角点当数角。

**怎么造**：让孩子先给**被数对象本身**编号，再回答：给段的肚子编号、给每个小正方形编号。编号写在点上还是段上一眼可见，等于把推理链画在卷子上。编号之后再问总数与单位量，错无可错。

## 3. 错题诊所

**治什么**：原题复现。让孩子亲手推翻那条错边。

**怎么造**：把原题搬进卷子（图重绘、参数一致），附上原来的错答案，写成「小明说：……」。常用的几问：

他数的、想的是 A 还是 B（指认对象）→ 正确的应该是多少（重做）→ 用校验边验一遍，错答案过不了关（亲手推翻）→ 一句话告诉小明他错在哪。不必每问都出，挑这次要测的。

用「小明」不用「你」：诊别人的错没有防御，诊出的是同一条边。

**变体 · 现成错答**：病人不必是孩子本人。家长代笔、教辅或同伴的现成错答同样可以进诊所（注明「有人这样填了」）。孩子零作答时，这是唯一现成的「病人」：先让他验（错答可能局部成立，如不等式成立但不是最大），再追问题目真正问的是什么，让他自己推出正解。范例见 `examples/unit-fraction-extremum`。

## 4. 校验边

**治什么**：给孩子一条能独立执行的恒等关系，写完答案自己验。

**怎么造**：选边的标准有两条——只用已过关的节点就能算；算出的矛盾要足够刺眼（10 × 1/11 ≠ 1）。放在卷首或自查清单里反复出现，比只出一道题更容易变成习惯。

| 领域 | 校验边 |
|---|---|
| 分数 | `一份 × 份数 ＝ 1` |
| 测量 | `起点刻度 + 走了几格 ＝ 终点刻度` |
| 乘法 | `积 ÷ 一个因数 ＝ 另一个因数`（或用连加验乘法） |
| 面积 | `拼回去要严丝合缝 / 总面积 ＝ 各块之和` |
| 不等式填空 | `把填的数代回原题`——方向对不对、是不是最贴边的那个（成立 ≠ 最大，相等 ≠ 大于） |

## 5. 反填极值脚手架

**治什么**：正向题反过来出（已知不等式、反填数字，还要最大/最小）。孩子要连翻三层：模型（谁大谁小）→ 反演（由不等号推出未知量的范围，方向翻转）→ 极值（在范围里贴边取，边界本身排除）。

**怎么造**：把动作印成卷面上的固定两步——「第一步，定范围（圈方向）；第二步，贴着边界取」，每步一行、留空给他走。再配一道**边界探针**（能不能取边界那个数、为什么），单测第三层。毕业题就是原题型去掉脚手架。范例见 `examples/unit-fraction-extremum`。

## 6. 规则对判别

**治什么**：防串线。节点自带成对规则时（分子都是 1 看分母 / 分母相同看分子；同类如周长 vs 面积），单条规则练得再熟，混在一起仍会串——串的是**选规则**那一步，不是规则本身。

**怎么造**：混编题组。每题第一个动作是圈出「这次用哪条」（看分子 / 看分母），第二个动作才是比较。

**判读**：分两层。单项对、混编错 = 判别边断，练判别，不练比较。

## 7. 迁移题与毕业题

**治什么**：收口。确认修好的是边，不是原题的长相。

- **迁移题**：同一条边换一个生活外壳，图形、数字、问法全变，只留结构。选外壳的标准：孩子没法背题型，只能调结构。范例：「平均剪成 10 段要剪几刀」——剪刀数 = 段数 − 1，与点段关系同构。
- **毕业题**：全卷图谱的一次综合，至少串起两个节点，且含一个小陷阱。放在最后，过了才算图谱接通；家长页的「收官」判据就指它和原题复测。范例：两颗 ★ 相隔几份——既要读位置，又要数两人之间的段。

## 8. 有提示 / 拿掉提示对照

**用处**：大人说「单独问他会，做题时就忘」。要测的不是概念，而是做题那一刻概念有没有被叫出来。

**怎么造**：同一类题混排，特意让容易出错的题紧跟在刚用过默认做法的题后面（同分子比较紧跟在同分母比较之后）。先出一组带提示的（每题先圈「这次看分子还是看分母」），再出一组拿掉提示的。两组对照着读：有提示对、没提示错，就是触发问题；两组都错，回到概念。例见 `examples/fraction-compare-order`。

## 判读的写法（家长页）

家长不必懂数学，对号入座就行。好用的写法：

> 第 X 题答成 A（写出预期的典型错答，如「读末数答 8」）→ 节点 N 没过 → 实物游戏 G（两三分钟）→ 回到第 M 题的动作重做。

- 错答要**预写出来**，家长对号入座，不靠家长理解数学；
- 实物游戏优先于再做纸题——断边多在实物层，纸面重复只是练流程；
- 写明怎样算修好：一般是原题复测答对，且讲得出关键关系（如「点数＝段数＋1」）。

## 已见误解模式清单

只存模式，不存某个孩子的情况（那在孩子的档案里）。遇到新模式就加一行；读照片时扫一遍，像的话有现成的探针可以借。

| 模式 | 长相 | 典型探针 |
|---|---|---|
| 点段不分 | 数端点/刻度当份数，分母、总数多 1 | 篱笆题（柱子 vs 栏杆）、编号写进肚子、剪刀题 |
| 0 无起点义 | 0 只当「没有」，量东西读末数、把 0 改成 1 再数 | 移位量、断尺量、从任意刻度起画定长线 |
| 定义会背、图上不会 | 背诵题全对，换表征就错 | 同一概念换三种表征连出（实物图 / 线段图 / 数轴） |
| 整体认错 | 单位「1」指错对象（把一份当整体、把多份当整体） | 整体涂色指认、同一图问两次「这里的 1 是谁」 |
| 零作答（启动处断链） | 整题空白、无猜测痕迹；下游断链通常会留猜值，空白指向第一环 | 从最上游正向题起逐层放行的探针梯 |
| 极值不贴边 | 范围推对了，却取范围内部的值、或把边界本身取进来；把「不等式成立」当「最大/最小」 | 边界探针（能不能取边界）+ 代回验：成立 ≠ 最大、相等 ≠ 大于 |
| 规则对串线 | 成对规则单练都对，混编时选错规则（如同分母比较套用「分母大者小」） | 混编判别题：先圈「看谁」再比较 |
| 默认做法抢先 | 单独做会，混排时被刚用过的默认做法带跑（整数「数大的大」搬到分母上） | 有提示 / 拿掉提示对照，易错题紧跟默认做法之后 |
| 排队不回读 | 两两比较都对，串成一条链时丢掉已得结果 | 排好后从左到右读相邻两个 |
| 位置/数量错接 | 两个量身份互换：把数对了的格数写进终点刻度槽（错值＝题中另一正确量，巧合检验可判），再按错位的值二次运算；常伴回代校验边缺失（起点＋格数落不回终点也无人拦） | 两量分工反序填（先数格写格数、再回头读终点）、每题强制回代一行（起点＋格数＝？对着图核终点） |
