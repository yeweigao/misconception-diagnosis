# 孩子档案的格式

档案是 `<孩子>/learner.json`，用 `scripts/learner.py add <孩子> <batch.json>` 写入。batch 只写这次新增或变化的部分，脚本负责合并：新 id 新建，旧 id 更新，证据只追加，不覆盖。

## 一个 batch 的样子

下面是一次「读完照片、出了卷子」之后写入的内容：

```json
{
  "child": { "grade": "三上" },

  "sightings": [{
    "date": "2026-11-12",
    "source": "教辅《分数的大小比较》课时3（照片在 2026-11-12-分数比大小/）",
    "summary": "三处先错后改对，其余全对；涂改是谁促成的不知道",
    "items": [
      { "item": "1(1) 同分母三个数排序", "correct": true, "nodes": ["cnm_p227"] },
      { "item": "1(2) 圆饼 1/3 与 1/5", "answer": "先写 1/3<1/5，后改对", "correct": false,
        "nodes": ["cnm_p227"], "note": "紧跟在同分母一组之后" }
    ]
  }],

  "experiments": [{
    "id": "e1",
    "title": "比之前，先停一下",
    "file": "2026-11-12-分数比大小/比之前先停一下.pdf",
    "tests": ["b1", "b2"],
    "predictions": [
      { "item": "第5题(3)行：同分子紧跟同分母",
        "if": { "b1 成立": "写反", "b1 不成立": "写对" } }
    ]
  }],

  "beliefs": [{
    "id": "b1",
    "claim": "混排做题时，刚用过「数大的大」，会把它搬到分母上；单独做概念题会",
    "nodes": ["cnm_p227", "见到分数先停"],
    "status": "有支持",
    "next": "混排题组，有提示 / 拿掉提示对照",
    "evidence": [
      { "dir": "支持", "source": "照片", "what": "两处原答案都按分母升序排，第二处与图上顺序相反" },
      { "dir": "支持", "source": "家长口述", "what": "单独做会；刚用过数大的大之后容易错" }
    ]
  }]
}
```

卷子收回之后：

```json
{
  "experiments": [{ "id": "e1", "status": "已回收", "outcome": "有提示组全对；无提示组同分子两行都写反" }],
  "beliefs": [{ "id": "b1", "status": "测实",
    "evidence": [{ "dir": "支持", "experiment": "e1", "source": "e1 收回",
                   "what": "有提示全对，拿掉提示后同分子紧跟同分母的两行写反" }] }]
}
```

## 字段

**猜测 beliefs**

| 字段 | 说明 |
|---|---|
| `id` | 档案内唯一，如 `b1` |
| `claim` | 一句关于孩子、能被卷子否掉的话 |
| `nodes` | 挂在哪些节点上：骨架用 `cnm_…`；课标以下的认知节点用一句短命题当名字 |
| `status` | 猜测 / 有支持 / 测实 / 推翻 / 已解决 |
| `next` | 下一步怎么测或怎么修 |
| `evidence` | `{dir: 支持\|反对, source, what, experiment?, date?}`；来自收回卷子的，写 `experiment` |
| `polarity` | 可选。猜测默认说的是一个问题；说的是「他会什么」时写 `"会"`（如「单独做时懂份越多每份越小」） |
| `related` | 可选。相关但本身没问题的课标节点，比如被「借」来规则的整数比大小。地图上会画出来、连上线，但不产生状态 |

状态的唯一硬规则：除「猜测」外都要有证据；「测实」「推翻」「已解决」要有带 `experiment` 的证据。

**看到的 sightings**：`{date, source, summary, experiment?, items: [{item, answer?, correct, nodes?, note?}]}`。做对的题也记，它们说明他会什么。收回的卷子也记成一条，写上 `experiment`：卷子上做对的题算「测实会」，平时作业上做对的只算「看到会」。

## 节点状态怎么算

不存，每次从上面三样算（`show` 列出，`map` 画出）：

| 亲眼看到的状态 | 来自 |
|---|---|
| 问题·测实 | 挂着一条「测实」的问题猜测 |
| 有问题 | 挂着一条「有支持」的问题猜测 |
| 存疑 | 挂着一条还是「猜测」的猜测，或者做错了却还没有猜测解释它 |
| 会·测实 | 问题猜测「已解决」、会的猜测「测实」，或收回的卷子上做对 |
| 看到会 | 平时作业上做对，或会的猜测「有支持」 |

几种情况同时有时，按表里从上到下取第一个；「做错了还没解释」排在「会·测实」之后。地图上另有三种推断状态（推断会、上游待查、可能受影响），规则见 `scripts/learner_map.py` 文件头。

**卷子 experiments**：`{id, date, title, file, tests: [猜测 id], predictions: [{item, if: {情形: 预期答法}}], status: 待做|已回收, outcome?}`。

## 想加字段

格式不是封闭的：脚本原样保留它不认识的字段。觉得某类信息值得长期记（比如孩子用的教材版本、常犯的书写问题），直接加；用了几次确实有用，再回来补进这份说明。
