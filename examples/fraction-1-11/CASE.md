# 范例全案：数轴十等份，一份答 1/11（2026-11-10）

skill 的第一个完整案例。新案例照这个深度做，尤其是第三步追到实物层、第四步四种固定件齐全。

## 输入（三件齐）

- **原题**：数轴 0 到 1 平均分成 10 份，问一份是多少。原图见 `original-photo.jpg`（家长手绘的线，只画了第一个刻度——她没画全，口头说明共 10 份）。
- **孩子的答案**：1/11。
- **作答过程**（关键证据）：他自己在题目下把 0 改成 1，然后顺着刻度一路写到 11，于是认为一份是 1/11。

## 第一步：推理链还原

改 0 为 1 → 给每个刻度点编号（1、2、3……11）→ 一共 11 个数 → 分母取 11 → 一份是 1/11。

链是自洽的：错不在计算，在第一步——他用**自然数点名**的图式处理了一个**测量**对象。

## 第二步：骨架定位

`taxonomy_lookup.py cnm_p079 --chain` → 「认识几分之一」，三年级上册第 6 单元；先修链：除法的意义（soft）、认识二分之一（hard）→ 平均分（等分/包含）→ 乘法。

判断：这条链上的技能（平均分、除法）不是他的问题——他会平均分，也知道分母的定义。骨架层无断边，病在下面一层。这一步的价值是**排除**：不许把卷子出成「先补平均分」。

## 第三步：误解层图谱（待补的边按依赖序）

1. **0＝起点**（他只有 0＝没有）：0 没有长度，是起跑线；因为 0 是「没有」，他才理直气壮把它改成 1。
2. **长度＝走过的格数**：测量不是读末尾的数，是从起点走过的单位个数。数轴就是尺子——这是跨 strand 的桥，骨架图谱里不存在（分数↔测量零连边）。
3. **点 ≠ 段，点数＝段数＋1**：10 段必然 11 个点；他数的是点。
4. **分母数段**：平均分几段，分母就是几。接错的边是「分母←最后的编号/点数」。
5. **校验边**：一份 × 份数 ＝ 1（10 × 1/11 ≠ 1，他自己能算出来打脸）。

每条边都能落到实物：尺子、栏杆、剪绳子。图谱到此建完。

## 第四步：出卷（终版见 worksheet.pdf，出卷脚本 build_worksheet.py）

五大题对应五条边，总分 100，一次二三十分钟：

- 一、量一量（节点 1–2）：对齐量 → 移位量 → 断尺量，撤支架三件套原样；
- 二、分一分（节点 3）：篱笆（7 柱 6 栏）+ 点段表 + 反填「点数 11 → 段数」；
- 三、搬一搬（桥）：把尺子的「一格」搬进 0 到 1，涂色一份认 1/4；
- 四、认一认（节点 4）：给段肚子编号答 1/6、1/10（原题参数复测）；点数陷阱题；第 9 题错题诊所——原题 + 他的 1/11，让他自己诊、用校验边推翻；
- 五、走一走（k/n）：读 ★、补刻度、自己标、剪刀迁移题、两颗 ★ 毕业题。

家长页：答案同源（脚本同份参数算出）、判读树（卡在哪题回哪个节点）、每节点一个实物游戏、收官条件（原题答对 + 说出「点数＝段数＋1」）。

QA 实测：check_pdf 五页充实度 76 / 92 / 83 / 79 / 79，逐页看渲染图无重叠出界；所有数轴、尺子的刻度数由脚本参数生成，与答案逐题核对一致。

## 附记（2026-11-10 晚，双源化后补）

本案是双源分工的由来：骨架定位用了 cn-math（结论是「骨架无断边」），误解层当时全靠推理自建。事后查 Marble 的教学研究，「Fractions on a number line」节点的第一条常见误解逐字就是本案的病——"Treats the number line like a ruler — counts tick marks instead of equal segments（IES Roadblock 2.1）"，其教学建议（预分线 → 地标线 → 无标线；b 等份只需 b−1 个内点）与本卷的撤支架设计同构。此后第二步固定顺手查 Marble 研究记录作误解候选（见 SKILL.md 第二步）。

## 本案沉淀的模式（已入题型库）

- 点段不分（数端点当份数）
- 0 无起点义（0 只当没有，读末数）
- 定义会背、图上不会（骨架诊断题能过、表征题不过）
