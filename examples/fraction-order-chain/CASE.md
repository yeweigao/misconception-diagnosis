## 一、输入与证据（家长确认，含当晚更正）

原题（RJ 三上「分数的大小比较」课时 3）：1、看图写分数并比较大小；2、填两条规则；3、看图写分数再比较；4、把 3/4、1/5、1/4 按从小到大排列。

照片逐块放大 3–4 倍逐笔看过，家长两次确认：

- **三处红圈＝家长标出的三处做错的地方**（原话：「怕你不知道圈起来告诉你」），不是待定疑点。
- **「我说了她之后改了的」**：讲解后才出现的订正（题4 下方两个大分数 1/4、3/4；题1(2) 右侧被划改的分母）是**提示后写的**，不算独立首答；不进推理链、不印进卷面。问卷里曾选过「家长圈的疑点 / 大人写的订正」，以家长随后补充的口述为准。
- **其余手写答案＝孩子独立写的**，可作证据。

孩子独立写的笔迹（能确认的部分）：

| 位置 | 写的是什么 | 判定 |
|---|---|---|
| 1(1) 三个 3×3 方格 | 2/9、4/9、6/9；`2/9 < 4/9 < 6/9` | 对（孩子在格里还编了 1–9 号） |
| 1(2) 左：圆分 3 份 / 5 份 | 图下 1/3、1/5；比较式写成 **`1/5 < 1/3`** | 数学成立，但与图下顺序对不上；家长圈出 |
| 1(2) 右：数轴 3/6、3/4 | 比较式里的分母被大人划改，原来写的**看不清** | 记为「不知道」，不猜 |
| 2 规则填空 | 「分子**大**的分数大」「分母**大**的分数反而小」 | 对 |
| 3(1)(2) 数轴 | `1/3 > 1/6`、`4/5 > 3/5` | 对 |
| 4 排序 | 前两步 `1/4 < 3/4`、`1/5 < 1/4` **都对**；最终写成 **`1/5 < 3/4 < 1/4`** | 错；家长圈出 |

其余痕迹：右上角另一题竖式 86×36=3096，与本案无关。

**提示后能改对**本身是判读信息：不是完全不会，所以卷子从放行探针起步，不从最基础重教。

## 二、拆题（先列做对原题要走的动作）

- 题4「三个数从小到大」＝ ① 两两比较（同分母看分子 / 同分子看分母）→ ② 分别写下两条不等式 → ③ 用**公共项**把两条式子接成一条链（传递）→ ④ 按链重排（不能照抄题面顺序）。
- 题1(2)「看图写分数并比较」＝ ① 分母＝平分的份数、分子＝取走的份数 → ② 选规则比大小 → ③ 把结果写成 `A ○ B`：左边的数必须真的比右边小，换位置必须换符号。

**两处的接缝**：分数比较在 `cnm_p227`（三上），不等号方向与整数序在 `cnm_p029`（一下），图谱里两支零连边；「多条不等式合成一条链」图谱里根本没有节点，是本案补的跨界桥。

## 三、推理链：哪些是证据，哪些是猜测

有证据的：① 看图写分数全对；② 两条规则会背会填；③ 单组比较（同分母、同分子）全对；④ 题4 前两条不等式都填对；⑤ 最终链把 3/4 和 1/4 颠倒；⑥ 题1(2) 左把两数调换后写 `<`。

**由此排除**：不会比大小、规则不会背、整数偏见（若按「分母大分数大」，题3 的 `1/3 > 1/6` 不会写对）、单纯不会取最值（不是本题型）。

**巧合检验**：题4 最终链 `1/5 < 3/4 < 1/4` 里，后两项 `3/4、1/4` 恰好保持题面给出的三个数 `3/4、1/5、1/4` 的相对顺序——指向「只判断了谁最小，其余照抄题面」，不是角色错接（错值不是题中另一个本应正确的量）。这是候选，不写成结论。

挂起的猜测（**只进探针，不进卷名 / 路线图 / 诊所台词**）：

| id | 猜测 | 挂在哪个节点 |
|---|---|---|
| b1 | 不等号没有方向感：只会用 `<`，靠调换两数的位置表达大小，换位置不换符号 | `cog_ineq`（认知） |
| b2 | 两条不等式不会经公共项接成链；或只排了「谁最小」，其余照抄题面顺序 | `bridge_chain`（跨界桥） |
| b3 | 没有一条统一的标尺（同一整体 / 同一数轴）来摆多个分数 | `cog_ruler`（认知） |
| b4 | 成对规则混编时串线（题2 会背、混着做选错规则） | `cnm_p227` 判别边 |

b4 由题3 的混编题全对基本压住，仍留一组判别探针。**三处「做错了」是事实；断在哪条边仍是猜测**——这是本卷所有探针存在的理由。

## 四、双源定位（脚本实跑，每个动作都查）

- `cnm_p227 简单的分数大小比较`（三上第 6 单元）：达标标准两条（分母相同分子大的大；分子都是 1 时分母大的反而小）。题库里 `4/9、1/9、5/9 中最大的是哪个` 与题4 的三数排序同构——**借了「三数排序」这个结构，参数全换**。
- `cnm_p226 认识几分之几` / `cnm_p079 认识几分之一`（直接先修）：分母＝平分的份数、分子＝取走的份数。题库 `分数的分母表示什么` 只测背诵，测不出本案的病。
- `cnm_p029 数的顺序、比较大小`（一下，题库 `在 47、74、39、58 中最大的是`、`比 7 大又比 9 小的数是几`）：**整数序支线**，与分数支零连边，正是接缝。
- Marble `mt_IfEgu0X449 / mt_HnKbuCliNS / mt_SsLWS_APM7`：达成证据含 `Order 1/2,1/3,1/4,1/5 from largest to smallest`；常见误解 `Cannot place the fractions consistently on a number line to check the order`（支持 b3 作候选）、whole-number bias、over-correction、算完不回看；教学建议 aligned bars / shared number line / looking-back check。都只是候选，未经孩子卷面验证，不硬套。

「骨架层无断边」不当结论写：四条支线各留了放行探针（第一、二大题）。

## 五、本案图谱（数据写进脚本，卷首路线 / 大题标注 / 家长页图 / 覆盖表同源）

八个节点，三种身份：

- 课标：`cnm_p079`、`cnm_p226`、`cnm_p227`、`cnm_p029`（一年级，接缝）
- 认知（课标以下）：`cog_ineq`「不等号是有方向的关系」、`cog_ruler`「多个分数共用一把尺」
- 跨界桥：`bridge_chain`「两条式子经公共项接成链」
- 原题 ★：三处错题落点

依赖边为实线；`cnm_p227 → cog_ineq`、`cog_ineq → bridge_chain` 两条**待确认接错的边**画红虚线；四个待测节点画虚框。追到实物层：数字卡片对调（不等号方向）、同一根尺贴卡片（统一标尺）、三张卡片把公共那张放中间（接链）、纸条与饼（份数）。家长页开头的图由 `GRAPH / EDGES` 同一份数据生成，`coverage()` 表也由它生成。

四种固定件齐全：撤支架三件套（两组，各自架在待测边上）、错题诊所、校验边（每个 `<` 代回验，卷首规矩 + 卷末自查 + 家长页习惯）、迁移与毕业题。题目内部按 CPA 排（情境 → 图示 → 抽象），动手游戏只放家长页。

**不泄题**：探针参数全部避开原题的 3/4、1/5、1/4，原题参数只在第六大题出现；订正后的正确答案不印进卷面；第一题的等分条用 `bareStrip()` 画，不自带分数标签。二选一题合计低于三成分值，每卷多处要求写出理由。

家长页：开头画知识图谱、逐题答案、分支式判读树（「答成 X → 节点 N 没过 → 回第几题 / 玩什么」）、实物游戏、收官条件、双源许可、图谱覆盖表。
