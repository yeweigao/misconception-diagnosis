# 范例三：分数比大小（触发缺失：概念在，做题时没被调出来）

与前两案的分工：范例一管追到实物层的深度，范例二管零作答 + 代笔的证据形态与出卷宽度；本案管**两种新证据**——孩子**自己涂改过**（先错后对、过程缺失、动因未知），以及**大人的口述**（「单独问概念题他会，连着做就忘」）。后者把「概念缺失」和「触发缺失」分开了，卷子的重心随之改变。

## 原题与证据

教辅《分数的大小比较》一页（三上，夯实基础 + 创新思维）。红框圈出三处涂改，每处都是「先错、后改对」：

| 题 | 先写的（错） | 改成（对） |
|---|---|---|
| 1（2）圆饼：1/3 与 1/5 | 1/3 ＜ 1/5 | 1/5 ＜ 1/3 |
| 1（2）数轴：3/6 与 3/4（左图分 6 段、右图分 4 段） | 3/4 ＜ 3/6 | 3/6 ＜ 3/4 |
| 4 排队：3/4、1/5、1/4 | 1/5 ＜ 3/4 ＜ 1/4 | 1/5 ＜ 1/4 ＜ 3/4 |

同一页上没有涂改的对题：1（1）同分母 2/9 ＜ 4/9 ＜ 6/9；3 叠放数轴比 1/3 ＞ 1/6、4/5 ＞ 3/5；2 两条规则的口述填空；4 的两步比较（1/4 ＜ 3/4、1/5 ＜ 1/4）。读分数全对。

**家长口述（已确认，2026-11-12）**：这个孩子「做着做着就忘了分数和整数比大小是反过来的」；单独让他做概念题，简单的就会；容易在**前一题刚用过「数大的大」之后**出错，隔一道别的题就好些。

**证据缺口**：作答过程缺失；涂改是自己发现的，还是被提示、对过答案之后改的，不知道；第 2 题两个空里有叠写笔迹，看不清是否改过。

## 归因

**链 A（两处比较题的原答案）**：读图写分数（对）→ 按「分母的数大＝分数大」排序（5＞3 → 1/5 大；6＞4 → 3/6 大）→ 写成 1/3 ＜ 1/5、3/4 ＜ 3/6。证据：两处原答案都按分母升序排；**第二处与图上左右顺序相反**，排除「照图序抄」；Marble「Comparing fractions（age 8+）」误解清单第一条（whole-number bias）与之吻合。

**触发缺失（家长口述 + 题序）**：圆饼题紧跟在 1（1）同分母那一组之后，那一组里「数大的分数大」是对的；他很可能把这个手感从分子搬到了分母上（推断，照片证明不了）。概念单独做会，说明「份越多每份越小」这条边在；缺的是**做题那一刻的触发**——见到分数先停一下，问「这次比的是每一份，不是数字」。所以第一版（概念占一半）定位偏了：对一个概念在的孩子，再教一遍概念测不出毛病。

**链 B（排队题的原答案）**：两步比较都对 → 合并成链时写成 1/5 ＜ 3/4 ＜ 1/4，第一步已得的 1/4 ＜ 3/4 被丢了。这是**合并后没回读**，与触发缺失同属「没有自查动作」，但落在另一条边上（m4）。

**误解参考的使用**：Marble 另一条「over-correction」（学了「分母大反而小」用过头，同分母也反过来）原答案里没有直接证据，只作防守：题组里放同分母行，圈对规则才算数。

- 误解层（本案现场建）：
  - **m1 份越多，每份越小**：概念在（家长：单独做会），卷子只单独确认；实物上能验（一张纸条对折）；
  - **m2 见到分数先停：比的是每一份，不是数字**：**缺的边在这**（触发）。整数的默认做法抢在前面；

## 卷子结构（终版，5 页：学生 3 页 + 家长 2 页）

设计理由：概念只做确认；**主体是整数、同分母、同分子的混排题组**，同分子紧跟在同分母之后（原题就是这样出的错），先带「先圈」提示（甲组）、再拿掉提示（乙组），两组对照读。

一、先确认概念（情境 / 圆饼 / 脱图，单独做，10 分）→ 二、连着做（一）有提示，6 行（18 分）→ 三、连着做（二）拿掉提示，6 行（24 分）→ 四、排队：照着框 + 自己串、读一遍（13 分）→ 五、错题诊所（小明刚比完 2/9 ＜ 4/9，接着写 1/3 ＜ 1/5；以及 1/5 ＜ 3/4 ＜ 1/4，12 分）→ 六、迁移（菜地）与毕业（混排 4 行 + 排队，23 分）。

卷中用到的构造：探针＝二、三大题的有提示 / 拿掉提示对照（撤的支架是「提示」本身）；错题诊所＝第五大题；校验边＝卷首规矩（先停一下问自己；排好后相邻两个读一遍）；迁移＋毕业＝第六大题。答案只在家长页；家长页含答案、证据段、判读树、陪练游戏、覆盖表与收官。

## 新见的误解模式

两条都已补进 `references/question-patterns.md` 的模式清单：

- **默认做法抢先（定势干扰）**：概念单独会，连着做时被刚用过的默认做法带跑（整数「数大的大」搬到分母上）。探针：混排题组，同分子紧跟同分母；有提示 / 拿掉提示对照。
- **排队不回读**：两两比较都对，合并成链时丢掉已得结果。探针：照框走 → 自己串 → 排好后从左到右读相邻两个。
